# ブロックと動作の対応

## ブロックと動作の定義

各ブロックの抵抗値と、動作の対応は、以下のように定義します。
- 2.2k : forward
- 4.7k : left turn
-  10k : right turn
-  22k : backward
-  47k : loop


## ブロックの配置位置と動作の実行順序の定義

- ブロックの配置位置と、動作の実行順序は以下のように定義します。
- SWを押すと、op1から順にop12へ、順に動作を実行します。ただしその途中でブロックがない場合は、そこで動作実行を停止します。
- 実行対象のブロックが"loop"ブロックの場合は、サブルーチンコールとなり、サブルーチンのloop1からloop4を順に実行します。ただしその途中でブロックがない場合は、サブルーチンの実行をそこで終了し、メインのopの実行へ戻り、loopの次のブロックの動作へ進みます。
- 実行中のブロックのLEDを"赤"で200ms周期で点滅させます。

      col=0     1     2     3
row=0     loop1 loop2 loop3 loop4
row=1     op1   op2   op3   op4
row=2     op5   op6   op7   op8
row=3     op9   op10  op11  op12


# ブロックと動作の定義
- forwardとbackwardは、それぞれ前進と後進の動作を行います。移動量（エンコーダのカウント値）は、"COUNT_STEP_GO"で定義し、とりあえずは1000としてください。
- left/right turnは、それぞれ左と右に90度回転の動作を行います。移動量は、"COUNT_STEP_TURN"で定義し、とりあえずは1500としてください。

# 仕様の変更
- 動作中のLEDの点滅を、#define LED_BLINK_CYCLE として定義し、500msとしてください。
- 各動作の間に #define WAIT_AMONG_OPERATION で定義する時間だけ待機をいれてください（とりあえず500ms）
